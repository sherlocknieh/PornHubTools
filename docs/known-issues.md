# 已知坑

现象 → 原因 → 规避方式。遇到新的站点改版或环境问题，先在这里追加，再改代码。

## 脚本装了却完全没反应

**现象**：开发时 `npm run dev` 已启动、管理器里也看到了脚本，但目标页没有任何效果，控制台报 `violates the following Content Security Policy directive` 或 `Refused to load the script`。

**原因**：目标站点（如 PornHub）的 CSP 拦掉 `localhost:5173` 注入，脚本根本没执行。

**规避**：按 `development.md` 的说明，把 userscript-dev 技能里的 `dev-kit.mjs` 拷到 `.dev/`，用「拉取构建产物再注入」的方式调试；构建产物写 `.dev/build/`，不动要提交的 `dist/`。

## 热更新后出现两份功能

**现象**：改一次源码，页面上出现两套按钮/链接，或背景播放把原型包了多层。

**原因**：脚本管理器重新执行同一份脚本时，上一轮的观察器、监听器和注入节点还在。

**规避**：入口通过 `unsafeWindow.__USERSCRIPT_TEARDOWN__` 拆除上一轮再初始化；新增 handler 必须返回清理函数，否则拆不干净。

## PornHub 控件突然找不到

**现象**：某个功能在改版后静默失效，控制台没有报错。

**原因**：站点 class 名是混淆产物，改版会整体替换。

**规避**：只改 `src/handlers/pornhub/dom.js`；把选择器写成契约，业务代码不做兜底拼接。

## 图库列高来回跳

**现象**：图片陆续加载时列内容不断重新平衡，正在看的图被挤走。

**原因**：`column-count` 会随内容变化重新分配列高。

**规避**：`photoGrid.js` 在插入时一次性算好 `--pg-x/--pg-y`，新格子只进当前较矮的列，已有格子不复排；高度按 `--ratio` 或图片比例提前占位。改布局时保持这个「一次性装箱」性质。

## 扩展面板里脚本图标变成白球

**现象**：部分脚本管理器的面板把图标整体刷白，黑圆白字只剩白圆。

**原因**：不透明黑圆被反色或滤镜处理，字母与圆一起变白。

**规避**：`src/assets/icon.js` 的圆填充留 25% 透明，靠透明度差异保住字母。

## Tekjam 选了 Large photos 仍被改成多列

**现象**：用户在相册页切到 Large photos，脚本仍按默认列数排版。

**原因**：页面用 `data-aview="large"` 记录视图选择。

**规避**：`tekjam.js` 读取该状态，为 `large` 时恢复单列，其余情况才接管多列。
